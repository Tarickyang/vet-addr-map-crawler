# 給下一位 Codex：動物醫院業務工作簿本機工具

你接手的是可執行專案，不只是提示詞。先讀根目錄 `README.md`、`docs/VALIDATION.md`，再檢查使用者自己的設定與 data。不得改動其他使用者的臺北 Google 試算表。

## 使用者目標與必守規則

輸入【縣市】【出發點地址】【白牌機車／其他交通】【主來源網址】【次來源網址】，建立行政區分類的醫院名單與每組最多8家的拜訪行程。可跨區、不返程。主來源較新，有值優先；次來源補缺。無來源的電話、負責人不推論；生日初始空白，備注只放人工指示。排除與產品限制要由該使用者定義，不能將臺北禁訪名單套用到其他縣市。

九欄順序：行程總覽/天、地圖編號、醫院名稱、電話、地址、Google Maps、醫院負責人名稱、生日、備注。按天及站序排序；同一天同色，地圖數字同色。不用去灰底放末，名稱/備注紅字。地圖編號持久不重排，站序另列。生日、人工備注、規則與ID不得被來源更新覆寫。

## 執行與專案狀態

- Python 3.10+，WSL Ubuntu 建議24.04。`bash install.sh`、`bash run.sh`。
- UI 在 localhost:8765。預設資料 `data/`，可用 `VET_DATA_DIR` 改位置。
- 每個專案一個 UUID 目錄。project.json 是正式資料；runs 是不可變的歷史輸出。讀取使用者當前狀態再修改，不從範例重新覆蓋。
- `.venv/bin/python -m vetapp.cli list` 列ID。collect只更新名單；generate規劃輸出；update連續執行兩者。
- Python單元測試：`.venv/bin/python -m unittest discover -s tests -v`。
- Web端會以 flock 保護每個專案，生成圖表另有執行緒鎖。新增資料修改入口必須沿用鎖與原子寫檔。

## 擴充其他縣市來源

先實際讀來源格式與官方說明，再新增 adapter。不把所有網站都交給猜測欄位。完整下載優先；有分頁須驗證 count/頁數、空頁、重複。通用 `page_url` 只支援頁碼，cursor/offset須專用adapter。記錄來源更新日期時只使用來源明示內容，抓取時間另存。

合併規則刻意保守：同名同地址或地址電話同時吻合且唯一。改名/搬遷需要明確證據，不以名稱相似度直接轉移人工備注。沒有可靠關聯的舊院所保留在待確認，不推論歇業。新增更寬鬆的標準化須測試分院衝突。

目前通用資料可能缺縣市；有明確city欄位可拼成完整地址，否則需修正輸入，不能硬貼使用者所選縣市。經緯度須確認是WGS84；官方TWD97須根據該來源座標系統轉換，不把EPSG:3826套用所有離島。要提升全自動能力，優先增加該縣市官方門牌精確比對adapter，保留匹配門牌與來源，未匹配仍需人工處理。

## 路線與地圖的誠實界線

已做：容量群聚、最多8家、固定起點、不返程、有向矩陣、組內DP、路線實際查詢、名稱警示。
未做：全市最優分組、完整臺灣白牌access合法性驗證、即時交通、營業時段、離島分割、停車拜訪時間。Valhalla motor_scooter不代表白牌完全合法；名稱掃描不能認證。所有白牌路線保留待核對標籤。新增排除點應以當地證據為準，不照搬臺北。

地圖可匯入官方區界，未匯入就明示。底圖下載失敗仍可產座標示意圖，但必須在圖與validation標示。圖上同色跨區共享；不要要求單一分頁同色一定8點。圖片存在Excel bytes中，PDF由相同fig生成；不是IMAGE URL。數字為地圖ID不是站序。

## Google Sheets 若另行要求

本版僅輸出xlsx，不含OAuth或Google帳號寫入。使用者可自行匯入Sheets；不可宣稱Excel圖片轉換到Google必然成功。若使用者要同步，需另實作其帳號OAuth最小權限與增量人工欄位保留，並實際讀回驗證。永久Google圖片內嵌通常需Apps Script insertImage(blob)，不能用短效SAS URL或addChart冒稱PNG已插入。

醫院地點網址維持 `https://www.google.com/maps/search/?api=1&query=...` 且百分比編碼；XLSX用原生hyperlink，不使用舊google.com.tw/maps/place中文路徑或HYPERLINK公式。Google導航拆最多4站一段。

## 月更新與封裝

Windows腳本只在使用者執行後才註冊月排程。不能說交付檔案等於排程已啟用；關機不執行，本版未設定錯過補跑。匯入檔案不會自動更新；新的未定位院所會停止生成，保留舊成果並標記stale。

程式更新用 apply-update.sh，保留data與venv，備份舊程式。封裝不要包含data、.venv、私人的生日或備注、連線憑證。生成自解壓.run時不要混淆壓縮內容與可執行shell邊界；測試ZIP與RUN內容、腳本語法及保留data行為。

## 建議下一步

只有使用者指定新的縣市/網址後，再實測該來源與增加adapter。優先補官方地址座標、官方區界自動取得、可人工調整分組與白牌禁行資料；不是把所有缺失都改成忽略錯誤。功能新增後跑既有測試及一個真實路由樣本，對未測的Windows或手機實機如實說明。
